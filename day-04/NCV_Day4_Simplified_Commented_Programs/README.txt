NCV LEVEL 4 - DAY 4: THREE COMMENTED PRACTICALS

All sample datasets contain 250 input records, including intentionally invalid examples.

1. 01_student_results_txt.py uses learners.txt
2. 02_retail_excel.py uses retail_sales.xlsx (install openpyxl in Thonny)
3. 03_attendance_json.py uses attendance.json

THOnNY INSTRUCTIONS
1. Extract this ZIP to a folder.
2. Open one .py program in Thonny.
3. Set Thonny's working directory to this folder (or open the folder as the working directory).
4. Press F5 to run the program.
5. Inspect the output report, error log, and clean data files.

TEACHING NOTES
- Sections are numbered and commented.
- Students implement counting, aggregation, and sorting manually.
- Essential functions such as open, print, int, str, len (for index bounds), and format-specific library readers are retained.
- Sorting uses selection sort for transparency; it is not optimal for very large datasets.
- Risk categories are classroom examples, not validated predictions.
